# Celeste 像素皮肤制作套件

给[《蔚蓝》（Celeste）](https://store.steampowered.com/app/504230/Celeste/)做像素皮肤的一套工具。

**自己手绘**，下载动作对照工具和测试地图。**用 AI 辅助制作**，三个包都下载。

## 制作教程

解压后双击 `开始阅读.html`，按手头的素材选择起点。把教程包和对照工具的解压目录交给能看图、读写本地文件并操作对照工具的编程 Agent，让它从 `AGENTS.md` 开始读。已有工作目录可以直接用。

[下载教程包 v1.9.15](https://github.com/letch4le-bot/celeste-skin-toolkit/releases/download/v1.9.15/Celeste_Pixel_Skin_Tutorial_v1.9.15.zip)

## 动作对照工具

把皮肤和游戏原版并排或叠图，逐帧看动作、冲刺配色、对话头像和死亡粒子。解压后双击 `皮肤动作对照.exe`，先加载游戏目录，再加载皮肤。详细操作见包内的 `使用说明.html`。适用于 64 位 Windows 10／11。

[下载动作对照工具 v1.11.1](https://github.com/letch4le-bot/celeste-skin-toolkit/releases/download/v1.9.15/CelesteSkinLab_v1.11.1.zip)

## 游戏内测试地图

在游戏里试基础动作、道具、剧情和对话表情。首页可以切换背景色和关卡泛光。把 ZIP 直接放进 `Celeste/Mods/`，有旧版就先移出。需要 [Everest](https://github.com/EverestAPI/Everest) 1.6642.0 或更新版本，以及 [LuaCutscenes](https://github.com/Cruor/LuaCutscenes) 0.2.13。

[下载测试地图 v1.5.7](https://github.com/letch4le-bot/celeste-skin-toolkit/releases/download/v1.9.15/SkinPracticeLab_v1.5.7.zip)
