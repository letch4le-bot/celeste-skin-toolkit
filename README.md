# Celeste 像素皮肤制作套件

这套工具能帮助你制作《蔚蓝》(Celeste) 的像素皮肤。

如果你是自己手绘，可以直接下载**动作对照工具**和**测试地图**；如果想用 AI 帮你做，可以再下载**制作教程包**（也可以在右侧 [Releases](../../releases) 里一次全下）。

---

## 1. 制作教程

解压后阅读 `开始阅读.html`，并直接把教程包和下面两个工具一起丢给 AI。

- 下载：[Celeste_像素皮肤教程包_v1.9.14.zip](Celeste_像素皮肤教程包_v1.9.14.zip)

## 2. 动作对照工具

把像素小人、动作动画与游戏原版并排或叠图对比。解压后双击 `皮肤动作对照.exe` 即可运行。

- 下载：[CelesteSkinLab_v1.11.1.zip](CelesteSkinLab_v1.11.1.zip)

## 3. 游戏内测试地图

在游戏里检查皮肤的动作和配色。不用解压，直接把 ZIP 放进 `Celeste/Mods/`（前置需要 Everest 1.6642.0 或更新版本，以及 LuaCutscenes 0.2.13）。

- 下载：[SkinPracticeLab_v1.5.7.zip](SkinPracticeLab_v1.5.7.zip)
